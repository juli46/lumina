¿QUÉ ES LÚMINA?

Una plataforma para comprar belleza.

En Lúmina reunimos productos de diferentes categorías y marcas de belleza para que puedas encontrar lo que necesitas en un solo lugar.

Puedes realizar compras para uso personal, comprar productos para regalar o adquirir mercancía para comenzar y surtir un emprendimiento.

Compra según tu presupuesto

El valor de los productos de tu pedido determina el nivel de compra al que puedes acceder.

MONTOS DE COMPRA

Elige cuánto quieres comprar

En Lúmina manejamos diferentes niveles de compra. El nivel se determina por el valor de los productos incluidos en tu pedido.

NIVEL INICIAL

$100.000

Ideal para comenzar a comprar en Lúmina, probar diferentes productos o realizar una compra de menor volumen.

Desde $100.000 en productos
NIVEL INTERMEDIO

$500.000

Pensado para compras de mayor valor y para quienes necesitan surtir mejor su inventario o aumentar la cantidad de productos.

Desde $500.000 en productos
NIVEL MAYORISTA

$1.200.000

Para compras de mayor volumen, especialmente pensadas para emprendimientos que necesitan surtir una mayor cantidad de productos.

Desde $1.200.000 en productos
¿Cómo se calcula el monto?

El nivel de compra se calcula tomando en cuenta el valor de los productos incluidos en el pedido. El costo del envío no se suma para alcanzar estos montos.
